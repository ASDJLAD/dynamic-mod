# Dynamic

Analyzes the timing of your inputs and flags runs where in-game clicks don't line up with real keyboard, mouse or touch input, which is a common signature of bots and macros.

- Live HUD with click count and unmatched-input percentage
- End-of-run report (popup and saved text file)
- Statistical checks: unmatched inputs, phase locking, constant input delay, repeated intervals

Results are heuristics, not proof.
